# 🚀 Projeto Tabela-FIPE

Projeto desenvolvido para fins de estudo para a aula de ingestão de dados.

## 📌 Sobre o projeto

O objetivo é aplicar conhecimentos de programação e Ciência de Dados por meio de um projeto prático, explorando dados e ferramentas relacionadas utilizando a API da fipe.

## 🎯 Objetivos

- Praticar conceitos de programação.
- Desenvolver habilidades de análise e organização de dados.
- Aplicar conhecimentos de Ciência de Dados.
- Utilizar o Git e o GitHub para versionamento de código.

## 🛠️ Tecnologias

As tecnologias utilizadas podem ser consultadas nos arquivos do projeto.
